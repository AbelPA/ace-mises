# ace-mises

Ace-Mises is a software lab for building intelligent, agentic systems with a strong bias toward clean architecture, clean code, and disciplined engineering practices.

At its core, this repository explores a simple but powerful idea: high-quality software emerges when human intent, specialized subagents, and thoughtful constraints work together in a coordinated system. The project is designed to support vibe coding with subagents — fast, creative iteration driven by focused autonomous agents — while keeping the foundation solid through pre-commit checks, layered design, and explicit collaboration rules.

## Vision

We are building an Agent-Based Computational Economics framework inspired by the Mises economics school, especially its emphasis on:

- dispersed knowledge
- decentralized coordination
- entrepreneurial discovery
- emergent order
- market processes rather than central control

In other words, the repository treats software development as a kind of economic system: multiple agents with local knowledge contribute to a larger process of value creation, while governance, structure, and feedback loops keep the system coherent.

## What this project emphasizes

### Vibe coding with subagents

This repo embraces exploratory, creative development, but not in a chaotic way. The workflow is intentionally agentic: specialized subagents collaborate on focused tasks, each contributing a narrow slice of expertise while preserving alignment with the project’s architecture and intent.

The goal is not “throw prompts at the wall,” but to combine fast iteration with clear boundaries, shared objectives, and reliable execution.

### Pre-commit quality gates

Good ideas need discipline. Pre-commit checks act as a safety rail: they reduce drift, protect code quality, and keep the project from degrading into brittle, undocumented, or half-validated change sets.

This project treats quality checks as part of the design, not as an afterthought.

### Clean architecture

The repository is intentionally organized around a layered structure that separates concerns:

- domain logic
- application services
- infrastructure concerns
- console and web interfaces
- testing and validation

This keeps business rules stable, external systems replaceable, and the codebase understandable as it grows.

### Clean code

We value readability, intent, maintainability, and simplicity over cleverness. Code should be legible to the next engineer, easy to reason about, and robust enough to evolve without entropy taking over.

### Agent-based computational economics

The project sits at the intersection of software engineering and economic modeling. It is inspired by the Misesian view that complex coordination emerges from individual actors acting with local information and incentives. Applied to software, that means building systems where autonomous components interact, adapt, and optimize within constraints — rather than depending on a single centralized planner.

## Repository shape

This repository is organized to support a modular, layered architecture:

- src/domain — core domain models and business rules
- src/application — orchestration and application-specific workflows
- src/infraestructure — infrastructure and integrations
- src/console — operational entry points
- src/web — web-facing components
- src/tests — validation and behavior checks

## Core philosophy

Ace-Mises is built around a few principles:

- local expertise beats global control
- autonomous agents should be purposeful, not noisy
- architecture is an economic constraint system, not a ceremony
- code quality is part of the product
- emergent order requires intentional guardrails

## Why Mises?

The Mises school emphasizes the role of knowledge, entrepreneurship, prices, and decentralized decision-making in generating social order. We borrow that lens for software design: the system is not a rigid machine, but a network of specialized participants coordinating through constraints, feedback, and adaptation.

That framing is especially relevant to modern AI-driven development, where coordination between multiple subagents, tools, and responsibilities can quickly become chaotic without clear structure.

## In one sentence

Ace-Mises is a clean, agentic software project for exploring how subagents, quality gates, and Austrian-inspired economic thinking can shape better systems for AI-assisted development and computational modeling.
